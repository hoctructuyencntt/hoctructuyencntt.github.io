Nộp bài

Sinh viên có thể nộp file mã nguồn, file nén hoặc dán link bài làm. Hệ thống sẽ tự xử lý theo đúng hình thức nộp bài.

1. Nhập thông tin sinh viên.
2. Chọn file hoặc dán link bài làm.
3. Bấm nộp bài và chờ thông báo thành công.

Phiếu nộp bài

Sinh viên nhập đầy đủ thông tin cá nhân và bài nộp (theo hướng dẫn nhà giáo nếu cần).

Chọn file bài làm Hỗ trợ: .c, .cpp, .zip, .rar, .pdf, .docx, .html, .js. Tối đa 10MB.
Lưu ý: Nếu nộp link Googe Drive phải chọn chia sẻ đến mọi người và có thể chỉnh sửa được.
