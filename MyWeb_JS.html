00

Chuẩn bị thư mục JavaScript cho MyWeb

Mục tiêu: tạo cấu trúc đúng để mọi chức năng sau đều viết vào file JS riêng.

Dễ

Yêu cầu thực hành

  1. Trong repo MyWeb, tạo thêm thư mục js.
  2. Trong MyWeb/js, tạo file script.js.
  3. Mở file HTML chính, thường là MyWeb/html/index.html.
  4. Trước thẻ đóng </body>, liên kết file JavaScript.
Thêm vào cuối file HTML
<script src="../js/script.js"></script>
Kết quả cần có: website vẫn hiển thị như cũ, nhưng đã sẵn sàng nhận chức năng JavaScript từ file script.js.

Lỗi thường gặp

  • Đặt sai đường dẫn: js/script.js thay vì ../js/script.js.
  • Đặt thẻ script quá sớm trong head khiến JS chạy trước khi HTML được tải.
  • Tên thư mục viết hoa/lẫn lộn: nên thống nhất js.
Nộp: cập nhật repo và nộp link https://github.com/abc/MyWeb/js.
01

Kiểm tra JavaScript đã chạy bằng console và biến

Mục tiêu: biết file script.js đã liên kết đúng và ôn lại biến, kiểu dữ liệu.

Dễ

Yêu cầu thực hành

  1. Mở MyWeb/js/script.js.
  2. Khai báo các biến mô tả website cá nhân: tên website, chủ đề, số lượng ảnh, trạng thái hoàn thành.
  3. Dùng console.log() để in ra thông tin.
  4. Mở DevTools → Console để kiểm tra kết quả.
Gợi ý script.js
const siteName = "MyWeb";
let topic = "Chủ đề website cá nhân của em";
let imageCount = 5;
let isReady = true;

console.log("Website:", siteName);
console.log("Chủ đề:", topic);
console.log("Số ảnh:", imageCount);
console.log("Đã sẵn sàng dùng JS?", isReady);
console.log("Kiểu dữ liệu topic:", typeof topic);
Kết quả cần thấy: Console hiển thị đủ thông tin website, không có lỗi màu đỏ.

Kiến thức liên quan

  • const: dùng cho giá trị không gán lại.
  • let: dùng khi giá trị có thể thay đổi.
  • typeof: kiểm tra kiểu dữ liệu.
Nộp: file MyWeb/js/script.js có phần kiểm tra console.
02

Đổi nội dung tiêu đề bằng DOM

Mục tiêu: dùng JavaScript tìm phần tử HTML và thay đổi nội dung hiển thị.

Dễ

Yêu cầu thực hành

  1. Chọn một tiêu đề chính trong website, ví dụ thẻ h1 ở hero.
  2. Nếu chưa có, thêm id="mainTitle" cho tiêu đề đó.
  3. Trong script.js, dùng document.getElementById().
  4. Đổi nội dung tiêu đề hoặc thêm lời chào phù hợp chủ đề cá nhân.
HTML cần có
<h1 id="mainTitle">Website cá nhân của tôi</h1>
<p id="welcomeText">Chào mừng bạn đến với MyWeb.</p>
Gợi ý script.js
const mainTitle = document.getElementById("mainTitle");
const welcomeText = document.getElementById("welcomeText");

if (mainTitle && welcomeText) {
  mainTitle.textContent = "MyWeb đã có JavaScript!";
  welcomeText.textContent = "Nội dung này được cập nhật bằng file js/script.js.";
}
Kết quả cần thấy: khi tải lại trang, tiêu đề hoặc đoạn chào thay đổi sau khi JavaScript chạy.

Lỗi thường gặp

  • Trong HTML là id="main-title" nhưng JS gọi mainTitle.
  • Gọi sai chữ hoa/chữ thường trong id.
  • Quên kiểm tra phần tử có tồn tại trước khi đổi nội dung.
Nộp: cập nhật index.html và script.js, trọng tâm là link MyWeb/js.
03

Thêm nút chào mừng bằng sự kiện click

Mục tiêu: hiểu cách người dùng thao tác và JavaScript phản hồi.

Dễ

Yêu cầu thực hành

  1. Thêm một nút trong phần hero hoặc giới thiệu.
  2. Gán id="helloBtn" cho nút.
  3. Thêm vùng hiển thị kết quả id="helloResult".
  4. Trong script.js, dùng addEventListener("click", ...).
HTML cần có
<button id="helloBtn">Nhấn để xem lời chào</button>
<p id="helloResult"></p>
Gợi ý script.js
const helloBtn = document.getElementById("helloBtn");
const helloResult = document.getElementById("helloResult");

if (helloBtn && helloResult) {
  helloBtn.addEventListener("click", function () {
    helloResult.textContent = "Cảm ơn bạn đã ghé thăm MyWeb!";
  });
}
Kết quả cần thấy: bấm nút thì thông báo xuất hiện ngay trong trang, không dùng alert là tốt hơn.

Kiến thức liên quan

  • click: sự kiện xảy ra khi người dùng bấm.
  • addEventListener: cách gắn sự kiện chuẩn, tách HTML và JS rõ hơn.
Nộp: trong MyWeb/js/script.js có xử lý sự kiện click cho nút.
04

Ẩn/hiện nội dung giới thiệu

Mục tiêu: thay đổi trạng thái giao diện bằng class CSS và JavaScript.

Dễ

Yêu cầu thực hành

  1. Chọn một đoạn giới thiệu hoặc một khối nội dung dài.
  2. Bọc nội dung đó bằng phần tử có id="aboutContent".
  3. Thêm nút id="toggleAboutBtn".
  4. Trong CSS, tạo class .hidden.
  5. Trong JS, dùng classList.toggle("hidden").
CSS cần có
.hidden {
  display: none;
}
Gợi ý script.js
const toggleAboutBtn = document.getElementById("toggleAboutBtn");
const aboutContent = document.getElementById("aboutContent");

if (toggleAboutBtn && aboutContent) {
  toggleAboutBtn.addEventListener("click", function () {
    aboutContent.classList.toggle("hidden");
  });
}
Kết quả cần thấy: bấm nút lần 1 nội dung ẩn, bấm lần 2 nội dung hiện lại.

Chú ý

  • Không nên xóa hẳn nội dung bằng JS; chỉ ẩn/hiện bằng class.
  • Class .hidden nên đặt trong style.css.
Nộp: có chức năng ẩn/hiện nội dung trên website thật.
05

Menu tương tác cho website

Mục tiêu: thêm nút mở/đóng menu, phù hợp website responsive.

Trung bình

Yêu cầu thực hành

  1. Trong header, thêm nút menu có id="menuToggle".
  2. Thanh menu chính cần có id="mainMenu".
  3. CSS tạo class .menu-open hoặc .active.
  4. JS bấm nút sẽ thêm/xóa class cho menu.
HTML gợi ý
<button id="menuToggle" class="menu-toggle">☰ Menu</button>
<nav id="mainMenu" class="main-menu">
  <a href="#home">Trang chủ</a>
  <a href="#about">Giới thiệu</a>
  <a href="#gallery">Thư viện</a>
  <a href="#contact">Liên hệ</a>
</nav>
Gợi ý script.js
const menuToggle = document.getElementById("menuToggle");
const mainMenu = document.getElementById("mainMenu");

if (menuToggle && mainMenu) {
  menuToggle.addEventListener("click", function () {
    mainMenu.classList.toggle("active");
  });
}
Kết quả cần thấy: menu có thể mở/đóng bằng nút, đặc biệt hữu ích khi xem trên điện thoại.

Mở rộng

  • Khi bấm một liên kết trong menu, có thể tự đóng menu.
  • Đổi chữ nút từ “☰ Menu” sang “Đóng menu”.
Nộp: website MyWeb có menu tương tác bằng JS trong MyWeb/js.
06

Chọn màu hoặc chủ đề giao diện

Mục tiêu: dùng sự kiện change để thay đổi trạng thái giao diện.

Trung bình

Yêu cầu thực hành

  1. Thêm hộp chọn màu/chủ đề cho website.
  2. Gán id="themeSelect" cho thẻ select.
  3. Khi người dùng đổi lựa chọn, JS thay đổi class của body.
  4. CSS định nghĩa ít nhất 2 trạng thái giao diện.
HTML gợi ý
<select id="themeSelect">
  <option value="">Giao diện mặc định</option>
  <option value="dark-mode">Nền tối</option>
  <option value="warm-mode">Nền ấm</option>
</select>
Gợi ý script.js
const themeSelect = document.getElementById("themeSelect");

if (themeSelect) {
  themeSelect.addEventListener("change", function () {
    document.body.classList.remove("dark-mode", "warm-mode");
    if (themeSelect.value !== "") {
      document.body.classList.add(themeSelect.value);
    }
  });
}
Kết quả cần thấy: chọn một chủ đề thì giao diện đổi màu ngay.

Gợi ý CSS

.dark-mode {
  background:#111827;
  color:#f8fafc;
}

.warm-mode {
  background:#fff7ed;
}
Nộp: script.js có xử lý sự kiện change.
07

Tìm kiếm nhanh nội dung trong website

Mục tiêu: dùng sự kiện keyup/input để lọc nội dung đang có.

Trung bình

Yêu cầu thực hành

  1. Thêm ô tìm kiếm có id="searchInput".
  2. Các thẻ nội dung cần tìm kiếm gán class search-item.
  3. Khi người dùng gõ, JS lọc các thẻ có chứa từ khóa.
  4. Không phân biệt chữ hoa/chữ thường.
Gợi ý script.js
const searchInput = document.getElementById("searchInput");
const searchItems = document.querySelectorAll(".search-item");

if (searchInput && searchItems.length > 0) {
  searchInput.addEventListener("keyup", function () {
    const keyword = searchInput.value.toLowerCase().trim();

    searchItems.forEach(function (item) {
      const text = item.textContent.toLowerCase();
      if (text.includes(keyword)) {
        item.style.display = "";
      } else {
        item.style.display = "none";
      }
    });
  });
}
Kết quả cần thấy: gõ từ khóa thì chỉ còn các nội dung phù hợp được hiển thị.

Áp dụng vào đâu?

  • Danh sách bài viết.
  • Danh sách sản phẩm/dự án.
  • Danh sách ảnh hoặc chủ đề cá nhân.
Nộp: website có ô tìm kiếm hoạt động bằng JS.
08

Lọc gallery ảnh theo nhóm

Mục tiêu: dùng data attribute, click và điều kiện để lọc ảnh.

Khó hơn

Yêu cầu thực hành

  1. Trong gallery, mỗi ảnh/card có class gallery-item.
  2. Mỗi item có thuộc tính data-category, ví dụ food, travel, study.
  3. Tạo các nút lọc có class filter-btn.
  4. JS bấm nút nào thì chỉ hiện nhóm tương ứng.
HTML gợi ý
<button class="filter-btn" data-filter="all">Tất cả</button>
<button class="filter-btn" data-filter="travel">Du lịch</button>
<button class="filter-btn" data-filter="study">Học tập</button>

<article class="gallery-item" data-category="travel">Ảnh du lịch</article>
<article class="gallery-item" data-category="study">Ảnh học tập</article>
Gợi ý script.js
const filterButtons = document.querySelectorAll(".filter-btn");
const galleryItems = document.querySelectorAll(".gallery-item");

filterButtons.forEach(function (button) {
  button.addEventListener("click", function () {
    const filter = button.dataset.filter;

    galleryItems.forEach(function (item) {
      const category = item.dataset.category;
      if (filter === "all" || category === filter) {
        item.style.display = "";
      } else {
        item.style.display = "none";
      }
    });
  });
});
Kết quả cần thấy: bấm nút lọc thì gallery thay đổi theo nhóm ảnh.

Chú ý

  • data-category trong HTML phải khớp với data-filter trên nút.
  • Nên có nút “Tất cả” để khôi phục toàn bộ gallery.
Nộp: script.js có chức năng lọc gallery.
09

Kiểm tra form liên hệ trước khi gửi

Mục tiêu: dùng submit, trim và preventDefault để kiểm tra dữ liệu.

Khó hơn

Yêu cầu thực hành

  1. Form liên hệ có id="contactForm".
  2. Ô họ tên có id="fullName".
  3. Ô email có id="email".
  4. Vùng báo lỗi/thành công có id="formMessage".
  5. Khi submit, JS chặn hành vi mặc định và kiểm tra dữ liệu.
Gợi ý script.js
const contactForm = document.getElementById("contactForm");
const fullName = document.getElementById("fullName");
const email = document.getElementById("email");
const formMessage = document.getElementById("formMessage");

if (contactForm && fullName && email && formMessage) {
  contactForm.addEventListener("submit", function (event) {
    event.preventDefault();

    const nameValue = fullName.value.trim();
    const emailValue = email.value.trim();

    if (nameValue === "") {
      formMessage.textContent = "Vui lòng nhập họ tên.";
      formMessage.style.color = "red";
      return;
    }

    if (emailValue === "" || !emailValue.includes("@")) {
      formMessage.textContent = "Vui lòng nhập email hợp lệ.";
      formMessage.style.color = "red";
      return;
    }

    formMessage.textContent = "Thông tin đã hợp lệ. Cảm ơn bạn!";
    formMessage.style.color = "green";
  });
}
Kết quả cần thấy: form không tải lại trang; nếu thiếu dữ liệu thì báo lỗi; nếu hợp lệ thì báo thành công.

Kiến thức quan trọng

  • submit: sự kiện khi gửi form.
  • event.preventDefault(): chặn trình duyệt gửi form/tải lại trang.
  • trim(): loại bỏ khoảng trắng đầu/cuối.
  • return: dừng xử lý khi gặp lỗi.
Nộp: form liên hệ trên MyWeb có kiểm tra dữ liệu bằng JS.
10

Hoàn thiện, kiểm thử và nộp kết quả JS

Mục tiêu: kiểm tra website hoạt động ổn định sau khi thêm JavaScript.

Tổng hợp

Yêu cầu kiểm thử

  1. Mở website bằng trình duyệt, kiểm tra Console không có lỗi đỏ.
  2. Kiểm tra từng chức năng: menu, nút, ẩn/hiện, tìm kiếm, lọc ảnh, form.
  3. Kiểm tra trên kích thước màn hình nhỏ.
  4. Kiểm tra đường dẫn ../js/script.js hoạt động đúng từ file HTML.
  5. Đẩy toàn bộ thay đổi lên GitHub.

Tiêu chí đạt

  • Website cũ không bị vỡ bố cục sau khi thêm JS.
  • Ít nhất 5 chức năng JavaScript hoạt động.
  • JS được viết trong file riêng MyWeb/js/script.js.
  • HTML chỉ thêm id/class/nút/form cần thiết, không trộn quá nhiều JS inline.
  • Có thông báo lỗi thân thiện khi form nhập sai.
Kết quả cuối cùng: website MyWeb từ trang tĩnh trở thành website có tương tác: người dùng bấm, gõ, chọn, gửi form và thấy phản hồi ngay.

Không đạt nếu

  • Chỉ nộp file JS rỗng.
  • Không liên kết được JS vào HTML.
  • Copy code nhưng id trong HTML không khớp nên chức năng không chạy.
  • Form submit làm trang tải lại mà không kiểm tra dữ liệu.
