2) Biến, kiểu dữ liệu, toán tử

let const typeof ===
Giải thích như sổ tay: Biến là chiếc hộp có nhãn. Trong hộp ta cất dữ liệu. let là hộp có thể đổi đồ bên trong; const là hộp chốt nắp, gán lại sẽ lỗi.
Kiểu dữ liệu cơ bản
Number, String, Boolean, Undefined, Null
So sánh nên ưu tiên
=== và !== để tránh ép kiểu ngầm
let studentName = "An";
let age = 20;
const schoolName = "Cao đẳng Kỹ thuật";

console.log(typeof studentName); // string
console.log(typeof age);         // number
Checklist hiểu bài
☑ Phân biệt được let, const, var.
☑ Nêu được 5 kiểu dữ liệu cơ bản trong bài.
☑ Giải thích được vì sao nên dùng === thay cho ==.

3) Rẽ nhánh và lặp

if...else switch for while
Mẹo Head First: Rẽ nhánh = “chương trình ra quyết định”. Lặp = “chương trình làm việc lặp lại”.
let score = 8.7;
if (score >= 8.5) {
  console.log("Giỏi");
} else if (score >= 7) {
  console.log("Khá");
} else {
  console.log("Cần cố gắng");
}

for (let i = 1; i <= 5; i++) {
  console.log(i);
}
Cạm bẫy: Quên cập nhật biến đếm trong while có thể gây lặp vô hạn.
So sánh nhanh
if / else if / else: dùng khi cần phân loại theo điều kiện.
switch: hợp với so sánh một biến với nhiều giá trị cụ thể.
for: biết trước số lần lặp.
while: chưa biết trước số lần lặp.

4) Chèn JavaScript vào trang

3 cách trong bài: Inline, Internal, External.
<!-- Inline -->
<button onclick="alert('Xin chào')">Nhấn thử</button>

<!-- Internal -->
<script>
  alert('Hello');
</script>

<!-- External -->
<script src="../js/script.js"></script>
Kết luận nên nhớ: Khi làm bài thực hành nghiêm túc, ưu tiên external JavaScript vì dễ quản lý, dễ sửa và đúng phong cách tách HTML/CSS/JS.

5) DOM – cầu nối giữa JS và HTML

Hình dung: Trình duyệt đọc HTML rồi dựng thành “cây phần tử”. JavaScript không làm việc với dòng chữ HTML thô, mà làm việc với các đối tượng trong cây DOM đó.
<h1 id="mainTitle">Học DOM</h1>

const title = document.getElementById("mainTitle");
title.textContent = "Học DOM với JavaScript";

6) Sự kiện và preventDefault()

Nói gọn: Sự kiện là phản ứng khi người dùng làm gì đó: click, change, keyup, submit...
const btn = document.getElementById("btnEvent");
btn.addEventListener("click", function () {
  console.log("Đã nhấn nút");
});
event.preventDefault() là gì?
Nó chặn hành vi mặc định của trình duyệt. Ví dụ trong form, mặc định nhấn submit sẽ tải lại trang. Khi gọi event.preventDefault(), ta giữ trang ở nguyên để JavaScript kiểm tra dữ liệu trước. 
loginForm.addEventListener("submit", function(event) {
  event.preventDefault();
  alert("Biểu mẫu đã được xử lý bằng JavaScript");
});

7) Kiểm tra form

Mục tiêu thực tế: Không cho gửi dữ liệu rỗng, báo lỗi rõ ràng, hướng người dùng sửa đúng.
Bước 1: Lấy dữ liệu bằng value.
Bước 2: Dùng trim() bỏ khoảng trắng đầu cuối.
Bước 3: Nếu rỗng → báo lỗi.
Bước 4: Nếu hợp lệ → thông báo thành công hoặc xử lý tiếp.
const fullName = nameInput.value.trim();
if (fullName === "") {
  errorBox.textContent = "Vui lòng nhập họ tên";
}
